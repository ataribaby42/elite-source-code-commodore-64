# Compiled game cartridges for the Commodore 64 version of Elite

This folder contains the crt cartridge images for the Commodore 64 version of Elite, as produced by the build process. There is one crt file for each supported release. These crt images can be loaded into an emulator like VICE, or into a real Commodore 64.
