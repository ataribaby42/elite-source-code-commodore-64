# Compiled game tapes for the Commodore 64 version of Elite

This folder contains the TAP tape images for the Commodore 64 version of Elite, as produced by the build process. There is one d64 file for each supported release. These TAP images can be loaded into an emulator like VICE, or into a real Commodore 64.
